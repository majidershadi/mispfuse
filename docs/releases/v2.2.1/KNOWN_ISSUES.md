# Known limitations — 2.2.1

- Splunkbase online validation controls the final Enterprise and Cloud
  compatibility decisions. Local AppInspect cannot guarantee portal approval.
- The Configuration page is generated by UCC 6.5.3 and produces one local
  AppInspect future failure for its generated Mako base template.
- Splunk Enterprise 9.4 uses Python 3.9 only for MISPFuse extension points;
  Python 3.7 is intentionally unsupported.
- A live MISP server is required for end-to-end account, command, and alert
  action tests.
- Cloud deployment still requires Splunk Cloud vetting for this exact package.
