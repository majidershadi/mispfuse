# Use an app identity and complete release metadata

**Suggested labels:** documentation, branding, release  
**Status:** Resolved in 2.1.0

## Context

The visible product is labelled as an add-on and lacks complete icons/legal metadata.

## Acceptance criteria

- App title and package identity are consistent.
- Icons, privacy statement, license, and release notes are packaged.

## Resolution

The final release uses the `MISPFuse` app identity and complete assets.
